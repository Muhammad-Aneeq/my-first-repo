# my-first-repo

A practice repository for learning Git and GitHub basics.

## About

This repo is a sandbox for getting comfortable with everyday Git workflows:
creating branches, staging changes, writing good commit messages, and pushing
work to GitHub.

## Contents

- `demo.md` - a scratch file for experimenting with edits and diffs.
- `new_file.md` - a placeholder file created while practicing `git add`.

## Getting Started

Clone the repository and make a change:

```bash
git clone https://github.com/Muhammad-Aneeq/my-first-repo.git
cd my-first-repo
```

## Usage

Stage your work, then commit it:

```bash
git add .
git commit -m "Describe your change"
git push origin main
```

## Contributing
